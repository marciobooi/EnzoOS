# CamillaDSP 4.1.3 (pinned)

Pinned in `install.sh` (`CAMILLADSP_VERSION`) because the YAML schema must
match `server/player.js:generateCamillaConfig()`. Never bump casually.
Sources: github.com/HEnquist/camilladsp (tag v4.1.3): `README.md`,
`websocket.md`.

## Project integration
- Unit: `camilladsp.service`, `ExecStart=/usr/bin/camilladsp /home/pi/EnzoOS/camilladsp.yml -p 1234`.
- `-p 1234` binds **127.0.0.1 only** (verified live) — no `-a` needed for loopback-only.
- Config regenerated by `server/player.js:updateCamillaConfigFromSettings()` on every server start and on EQ/settings change; applied gaplessly via WS `SetConfig`. Manual edits to `camilladsp.yml` are overwritten.
- Volume: CamillaDSP's main fader via `SetVolume` (dB) owns the entire gain stage; hardware PCM volume is pinned to max by `ensureAsoundConf()`.

## WebSocket API — v4 command list (exact)
Send `"Command"` or `{"Command": arg}` as JSON text. Reply envelope:
`{"Command": {"result": "Ok"|"Error", "value": ...}}`.

- **General**: `GetVersion`, `GetSupportedDeviceTypes`, `Stop`, `Exit`
- **Status**: `GetState` (Running|Paused|Inactive|Starting|Stalled), `GetStopReason`, `GetCaptureRate` (measured Hz), `GetSignalRange`, `GetRateAdjust`, `GetBufferLevel`, `GetClippedSamples`, `ResetClippedSamples`, `GetProcessingLoad` (%), `GetResamplerLoad`
- **Signal levels** (per-channel dB): `GetCaptureSignalPeak/Rms`, `GetPlaybackSignalPeak/Rms`, `…Since [secs]`, `…SinceLast`, combined `GetSignalLevels`/`…Since`/`…SinceLast` → `{playback_peak, playback_rms, capture_peak, capture_rms}`, `GetSignalPeaksSinceStart`, `ResetSignalPeaksSinceStart`
- **Volume**: `GetVolume`, `SetVolume [dB]`, `AdjustVolume [dB]|[dB,min,max]`, `GetMute`, `SetMute [bool]`, `ToggleMute`; faders 0-4: `Get/Set/AdjustFaderVolume`, `Get/Set/ToggleFaderMute`, `GetFaders`
- **Config**: `GetConfig` (YAML), `GetConfigJson`, `GetConfigTitle/Description/FilePath`, `GetPreviousConfig`, `SetConfig [yaml]`, `SetConfigJson`, `SetConfigFilePath [path]`, `PatchConfig`, `Get/SetConfigValue [json_pointer]`, `Reload`
- **Validation** (non-destructive): `ReadConfig`, `ReadConfigJson`, `ReadConfigFile`, `ValidateConfig`, `ValidateConfigJson`
- **Devices**: `GetAvailableCaptureDevices [backend]`, `GetAvailablePlaybackDevices [backend]` (backends: Alsa, CoreAudio, Wasapi)

⚠ **There is NO `GetStatus` command.** `server/player.js:getCamillaStatus()`
sends `{GetStatus:null}` and always gets `Invalid` back (TODO §9.1). Use
`GetState` + `GetProcessingLoad` + `GetClippedSamples` + `GetCaptureSignalRms`.

## `devices` section — parameters we care about
| Param | Default | Notes |
|---|---|---|
| `samplerate` | — | Processing rate; both devices must support it |
| `chunksize` | — | Suggested 1024 @44.1/48k, 2048 @88.2/96k, 4096 @176.4/192k |
| `queuelimit` | 4 | Inter-thread queue; total buffered = 2×chunksize×queuelimit |
| `enable_rate_adjust` | false | Corrects clock drift capture↔playback. Supported on **Alsa playback**: "virtual clock tuning when available, otherwise async resampling". **We need this — see TODO §9.1 drift finding** |
| `target_level` | chunksize | Desired playback buffer level (samples) with rate adjust |
| `adjust_period` | 10 s | Drift-correction interval |
| `resampler` | null | `AsyncSinc` (profiles VeryFast/Fast/**Balanced**/Accurate — Balanced ≈ −170 dB noise), `AsyncPoly` (Linear/Cubic/Quintic/Septic — cheaper, needed for rate adjust without sinc), `Synchronous` (fixed ratio, no rate adjust) |
| `capture_samplerate` | =samplerate | Input rate before resampling |
| `silence_threshold` | null (dB) | With `silence_timeout` (s): pause pipeline when idle — we don't set these yet (TODO §9.2) |
| `stop_on_rate_change` | false | Stop if measured capture rate shifts >4% |
| `rate_measure_interval` | 1.0 s | Capture-rate measurement window |
| `volume_ramp_time` | 400 ms | SetVolume ramp |

Sample formats: `S16_LE`, `S24_3_LE` (3-byte), `S24_4_RJ_LE`/`S24_4_LJ_LE`, `S32_LE`, `F32_LE`, `F64_LE`.

## Dither filter (for 16-bit outputs — TODO §9.2)
`type: Dither` with `parameters.type`: recommended **Fweighted441** (9 taps)
or **Gesemann441** (8) for 44.1 kHz 16-bit; `Gesemann48` for 48 kHz; `Flat`
(triangular, rate-agnostic) as safe default; Shibata variants for hi-rate.
Only dither when playback format is 16-bit — skip for 24/32-bit.
